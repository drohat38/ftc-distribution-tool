# Public Distribution Map — Deploy Guide (Phase 3b)

The public distribution map is `src/index.html`: one self-contained HTML file that
reads three **published-to-web Google Sheet CSVs** and draws events, partner orgs,
and the lines connecting them. It is a sibling of the event map and deploys the
same way — its **own** Cloudflare Pages project, served from `src/`.

> **Privacy note.** This map is intentionally public (decision 2026-06-19, see
> `CHANGELOG.md`). It shows only the **non-contact** partner subset. Contact
> name/phone/email, agreement status, and `last_verified` are never published —
> the `Rebuild public view` action strips them. Don't paste a private-tab CSV URL
> into the config below; only the three URLs listed here.

---

## What it reads — the three published CSVs

| # | Tab | What's in it | How to publish |
|---:|---|---|---|
| 1 | `Partners_Public` | Non-contact partner subset (org name, city, address, lat/long, pathway, cold_storage, capacity, recurring_slot, status) | Generated by **FTC ▸ Rebuild public view**, then Publish to web → CSV |
| 2 | `Links_Public` | `PartnerID`, `EventID`, `active` | Same — generated by Rebuild public view, then Publish to web → CSV |
| 3 | `Events_Reference` | Public event display fields + lat/long | Publish to web → CSV (or just keep the event map's existing Events CSV — same data) |

### Step A — generate the public tabs
In the **Partners** workbook: **FTC ▸ Rebuild public view**. This (re)builds
`Partners_Public` and `Links_Public` from the private data. Re-run it any time the
partner data or links change.

### Step B — publish each tab to web as CSV
For **each** of the three tabs: **File ▸ Share ▸ Publish to web** → pick the tab
in the left dropdown → format **Comma-separated values (.csv)** → **Publish**.
Copy the URL it gives you. It looks like:

```
https://docs.google.com/spreadsheets/d/e/2PACX-…/pub?gid=<NUMBER>&single=true&output=csv
```

### Step C — paste the URLs into the map
Open `src/index.html`, find the `CONFIG` block near the top of the first
`<script>`, and paste:

```js
const CONFIG = {
  PARTNERS_CSV: "…Partners_Public CSV URL…",   // REQUIRED
  LINKS_CSV:    "…Links_Public CSV URL…",       // REQUIRED
  EVENTS_CSV:   "…Events_Reference CSV URL…",   // optional — defaults to the event map's Events CSV
  …
};
```

`EVENTS_CSV` already defaults to the event map's existing, already-public Events
CSV (same event data), so you can leave it as-is and skip publishing
`Events_Reference` if you prefer one fewer step.

## The Maps key (reuse the event map's key — do NOT make a new one)

The map needs a Google **Maps JavaScript API** key. Reuse the event map's existing
referrer-restricted key — no new key, no new billing relationship.

Two ways to supply it (same pattern as the event map):

1. **`?k=` URL param** (quick test / embed): open
   `https://<your-project>.pages.dev/?k=YOUR_KEY`.
2. **`FALLBACK_KEY`** (production default): paste the key into `FALLBACK_KEY` in
   the last `<script>` of `src/index.html`. It ships **blank on purpose** so no key
   is committed; paste the event map's key there before deploying.

**Referrer step (required):** in Google Cloud Console, add this project's
Cloudflare URL to the key's allowed referrers:

```
https://<your-project>.pages.dev/*
http://localhost:*        (local testing)
http://127.0.0.1:*        (local testing)
```

Only **Maps JavaScript API** is needed here — there's no geocoding at runtime (all
coordinates are pre-cached in the sheet).

## Deploy — a SEPARATE Cloudflare Pages project

Do **not** reuse the event map's Pages project. Create a new one so the two maps
deploy independently.

1. cloudflare.com → **Workers & Pages → Create → Pages → Connect to Git** →
   authorize → select the `ftc-distribution-tool` repo.
2. **Production branch:** `main`. **Framework preset:** None. **Build command:**
   (blank). **Build output directory:** `src` — serving only `src/` keeps the rest
   of the repo (apps-script, docs, PRD, reference…) off the public URL.
3. You get a URL like **`https://ftc-distribution-map.pages.dev/`** (the exact
   subdomain depends on the project name you choose). The map is served at the
   root. `git push` to `main` auto-deploys (~60s).
4. **Verify privacy:** visiting `…/AGENTS.md` or `…/PRD.md` should return the *map*
   (Cloudflare's fallback for unknown paths), NOT the file — confirming only `src/`
   is public.

After it's live, add that `.pages.dev` URL to the Maps key's referrers (above).

## How updates reach the live map

| Change | How it goes live |
|---|---|
| Edit partner data / links in the sheet | Re-run **Rebuild public view**; the published CSVs update within ~10 min, and the map auto-refreshes every 10 min |
| Code change to `src/index.html` | `git push` → Cloudflare auto-deploys (~60s) |
| New partner columns to publish | Edit `CONFIG.PUBLIC` in `apps-script/Code.gs` — but never add a contact/agreement field (privacy wall) |
